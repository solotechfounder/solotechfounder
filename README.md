## Brand-mark note

The social cards use compact typographic platform marks (`in`, `◎`, `GH`) rather than externally loaded brand SVGs. This keeps every SVG self-contained and request-free.

## GitHub-safe animation

All artwork is self-contained SVG using embedded PNGs/fonts, CSS and SMIL only. No JavaScript, `foreignObject`, remote fonts, image URLs or external stylesheets are used. Motion has readable final/base values and reduced-motion fallbacks.
